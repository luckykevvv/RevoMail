# Project Documentation

- `architecture/` contains architecture decision records, system diagrams, data-flow notes, and security decisions.
- `api/` contains API specifications, endpoint examples, error formats, and authentication flows.

Architecture decisions should be numbered and immutable once accepted, for example `ADR-0001-backend-stack.md`. Supersede an old decision with a new record instead of silently rewriting history.

Documentation must distinguish implemented behavior from proposals and must not contain secrets, personal mailbox data, or production credentials.
